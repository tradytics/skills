# Tradytics skills

Teach Claude Code, Codex, Cursor and other agents to pull options flow, dark pool prints, dealer exposure, prices, fundamentals, filings and more from the [Tradytics API](https://tradytics.com/docs).

```bash
npx skills add tradytics/skills
```

Then set your key from [API keys](https://tradytics.com/developer/keys):

```bash
export TRADYTICS_API_KEY="tdy_..."
```

| Skill | Covers |
| --- | --- |
| [tradytics](skills/tradytics/SKILL.md) | Every endpoint of the Tradytics API |

Generated from the Tradytics docs, so it changes with the API.
